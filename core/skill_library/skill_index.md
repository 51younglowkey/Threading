# Threading Skill Index

Last updated: 2026-08-11

## Reusable behaviour

### Threading Managed Workspace

Installable skill: `../skills/threading/SKILL.md`
Compatibility route: `skills/threading-dashboard/SKILL.md`

Use for Dashboard, existing-project adoption, Current State, Figma evolution,
chat reconciliation, linked GSA Pack, migration, update or doctor.

### Evidence Chain Discipline

File: `skills/evidence_chain_discipline.md`

Use when a project needs a stronger link between source material, interpretation, claims, design decisions, testing and limitations.

### Retrospective Warning System

File: `skills/retrospective_warning_system.md`

Use before a major presentation, document or project milestone to check that the process, criteria, testing and intended impact are visible rather than implied.

### Apply Taught Methods

File: `skills/apply-taught-methods/SKILL.md`

Use when selecting and applying a method such as systems mapping, Three Horizons, theory of change, design experiments, design ethnography or provotyping. Load a context-specific pack first when the method catalogue belongs to one.

### Frontdesk Framework Fix

Files: `frontdesk/dialogue_scope_current.md`, `frontdesk/frontdesk_framework_fix_mode.md`

Use when improving Threading's structure, skill library, templates, indexes or bounded tools rather than writing a project argument.

## Boundaries

- Do not invent evidence or participant quotations.
- Do not treat a framework as proof of a claim.
- Do not add personal project material to the reusable core.
- Do not create calendar or deadline automation in this edition.
