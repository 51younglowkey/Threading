# Frontdesk Framework Fix Mode

## Purpose

This frontdesk is the entry layer for improving Threading's structure, skills, templates, file routing and bounded tools without silently absorbing a user's private project content.

## Routing rules

| User intent | Route |
|---|---|
| Add or classify a reusable file | Source intake and provenance review |
| Ask what skills exist | `core/skill_library/skill_index.md` |
| Create a new skill | `core/skill_library/templates/skill_template.md` |
| Fix project structure | Framework maintenance |
| Improve evidence reasoning | `skills/evidence_chain_discipline.md` |
| Select a taught method | `skills/apply-taught-methods/SKILL.md` |
| Write a project argument | User-owned Managed Workspace, evidence-first workflow |

## Required behaviour

1. State which route is being used.
2. Read the relevant existing files before editing.
3. Make small structural fixes when the destination is clear.
4. Keep raw files separate from summaries and interpretations.
5. Do not treat a template or script as a skill unless it defines reusable assistant behaviour.
6. Ask before an action would expose, publish, delete or move private project material.
