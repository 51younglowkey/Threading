# Managed Project Workspaces

`projects/_template/` is the public scaffold for a complete local Threading
workspace. `projects/local/` is Git-ignored and stores each user's processed
project knowledge, decisions and outputs.

Raw Figma files, desktop archives, recordings and complete chat exports may stay
in their original locations. A local workspace may contain bounded derived text
and analysis when it records the source pointer, inspected scope, date and
confirmation status.

Legacy `profiles/local/` remains supported for migration only. New existing
projects should use `projects/local/<slug>/`.
