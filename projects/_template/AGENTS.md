# Local Threading Project Instructions

This directory is a private Managed Workspace for one school, research or design
project. Root Threading rules still apply; these instructions add project-local
behaviour.

1. Read `CURRENT.md` first for confirmed current state.
2. Read only the source, evidence, decision or iteration records needed for the
   current task.
3. Ask before inspecting any external local path, Figma file or chat archive.
4. Keep raw material in its controlled source unless the user explicitly asks
   for a bounded local copy.
5. Derived material must record source ID, location, inspected scope, date and
   status.
6. Treat imported/model-generated content as `candidate` until the user confirms
   it.
7. Do not change the current direction solely because a newer-looking file
   exists. Propose the candidate and ask the user.
8. Keep superseded states in history. Never rewrite earlier decisions to match
   the present direction.
9. Treat the linked GSA Pack as read-only. Write analysis here, not into the
   public pack.
