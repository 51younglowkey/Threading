# Threading — NOW

Updated: 2026-08-11

## Workspace

Threading is the reusable core extracted from a private academic workspace. It is intended for peers with different project contexts but similar needs around research organisation, evidence traceability, methods, design iteration and writing. An independent GSA Pack is available as an optional Design Innovation academic context.

Current status: **public-release candidate with an Agent-native text Dashboard, optional GSA Pack and standalone PDF/image index**.

Release decision (2026-08-11): the owner chose a public GitHub repository. Users
will view, clone or download Threading without collaborator access; changes should
come through forks and pull requests. Project profiles may live locally inside the
clone or at an explicitly chosen external path. The PDF/image index remains an
optional tool, not a core onboarding dependency.

```text
Threading
├── system rules and repository boundaries
├── optional GSA Pack with methods, reflection-document analysis and Stage 3 assessment guidance
├── evidence, reading, interview and prototype templates
├── project profile template and synthetic example
├── Agent-native text Dashboard and first-run onboarding
└── bounded indexing and file utilities
```
