# Threading Capability Guide

## 简短介绍

Threading 是一个在 Codex 中运行的本地 Project Knowledge Workspace。它可以
接管已经很复杂的研究或设计项目，把 Figma、本地文件和聊天历史中处理后的知识
连接到 Current State、evidence、decisions、prototypes、testing 和 writing。

直接尝试：

```text
帮我接管这个现有项目
Threading Dashboard
帮我找出当前真正工作的方向
整理已经导入的聊天记录
帮我整理 Figma 从前期到现在的变化
加载 GSA Pack 并告诉我怎么使用
根据 Stage 3 criteria 检查我的项目
帮我分析 Reflection Document 的结构
Update Threading
Threading doctor
```

## What Threading can do

- adopt a messy existing project into a private local workspace;
- propose and confirm a Current State without deleting history;
- organise bounded derived knowledge from Figma, local files and chat archives;
- preserve evidence and decision traceability;
- connect prototypes and drafts to learning questions and iteration;
- expose the optional linked GSA Pack with practical prompts;
- update the public core without touching ignored local workspaces.

Threading does not make imported model prose true, decide the current direction
without confirmation, or replace authorised assessment sources.
