# Current Dialogue Scope

Mode: Framework Fix

This route is for maintaining Threading's reusable functions and framework.

## In scope

- skill library creation and maintenance;
- workspace structure and file routing;
- source-intake, provenance and privacy rules;
- indexes, manifests, templates and bounded scripts;
- clear distinctions between skills, tools, templates, evidence, raw files and outputs.

## Out of scope for this route

- inventing research findings or participant quotations;
- deciding a user's project direction without evidence;
- replacing ethics or consent judgement;
- turning a user's private project archive into shared examples without a privacy review.

If a request is project-content heavy, route it to the user's own project profile and preserve the reusable core's boundary.
