# Project Profile Template

Copy this folder into `profiles/local/<project-name>/` before adding project-specific material.

This template contains placeholders only. Replace them with user-owned information locally; do not commit personal details to the reusable core by accident.

## Profile files

- `context.md` — brief, setting, question and boundaries
- `source_map.md` — pointers to Figma, local folders, repositories or other sources
- `status.md` — current phase, readiness and next action for the text dashboard
- `packs.md` — optional packs loaded for this profile (`none` by default)
- `evidence_log.md` — source and evidence records
- `decision_log.md` — dated decisions and alternatives
- `iteration_log.md` — prototype or draft changes and learning

## Privacy boundary

Keep raw recordings, signed consent, contact details, identifiable images and private administration outside the repository or in a separately controlled location.
